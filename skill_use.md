## Superpowers (суперсилы)

Superpowers — это дополнительные возможности, которые расширяют функциональность агента:

### Применение superpowers в проекте:

1. **telegram-mcp** — управление Telegram аккаунтом для уведомлений пользователей
2. **xai-api** — вызов Grok LLM для AI-функций, генерация контента
3. **context7** — получение актуальной документации по библиотекам и фреймворкам
4. **mcp-builder** — создание MCP серверов для интеграции с внешними сервисами

### Как использовать superpowers:

Перед любым ответом или действием:
1. Вызовите `using-superpowers` скилл для определения доступных возможностей
2. Выберите наиболее подходящий скилл для текущей задачи
3. При необходимости объедините несколько скиллов (например, `velopro-design` + `remotion` для создания промо-видео с фирменным дизайном)

## Правило выбора лучшего скилла

Для каждой задачи определите **один основной скилл** и, при необходимости, **дополнительные скиллы**:

| Задача | Основной скилл | Дополнительные скиллы |
|--------|---------------|----------------------|
| Создание UI компонента | `velopro-design` | `design-ui`, `frontend-design` |
| Создание промо-видео | `remotion` | `velopro-design`, `xai-api` |
| Отладка бага | `systematic-debugging` | `debug` режим |
| Реализация фичи | `test-driven-development` | `writing-plans`, `executing-plans` |
| Интеграция с Telegram | `telegram-mcp` | `xai-api` |
| Создание MCP сервера | `mcp-builder` | `xai-api` |
| Работа с БД | `neon` | `anaconda-intelligence` |
| Аутентификация | `auth` | `xai-api` |
| Документация | `content-research-writer` | `og` |
| Перед завершением | `verification-before-completion` | `requesting-code-review` |

## Пример комбинирования скиллов

**Создание промо-видео ВелоПРО:**
1. `velopro-design` — определить цветовую палитру и стиль видео
2. `remotion` — создать видео на React с анимацией электровелов
3. `xai-api` — сгенерировать текст для видео через Grok
4. `verification-before-completion` — проверить рендеринг видео

**Реализация новой фичи:**
1. `writing-plans` — составить план реализации
2. `test-driven-development` — написать тесты сначала
3. `systematic-debugging` — отлаживать по мере реализации
4. `verification-before-completion` — проверить сборку и логи
5. `requesting-code-review` — запросить ревью перед мержем

## Как применять скилл в работе

1. **Определите задачу** — что нужно сделать
2. **Выберите скилл(ы)** — основной и дополнительные по таблице выше
3. **Прочтите SKILL.md** — загрузите полное содержимое скилла
4. **Следуйте инструкциям** — выполните шаги из скилла
5. **Проверьте результат** — используйте `verification-before-completion`
