# ВелоПРО

Мобильное WebView приложение для аренды электровелосипедов и ремонта собственных С.И.М-устройств пользователей.

## О проекте

ВелоПРО — это приложение для аренды электровелосипедов и обслуживания собственных С.И.М-устройств (не арендованных в ВелоПРО). Все обновления доставляются через веб-сайт, который загружается в WebView контейнере Android-приложения.

## Основные возможности

### Аренда электровелосипедов
- Выбор арендуемого электровелосипеда с индивидуальной стоимостью
- Выбор срока аренды
- Автоматическое продление аренды в день окончания срока
- Оплата списывается в день окончания аренды на новый срок

### Платежи
- Автоматическое списание аренды со счета кошелька или банковской карты
- Привязка банковской карты для автоматической оплаты подписки
- Работа с платежным агентом РобоКасса (Robokassa.com)
- Пополнение кошелька с банковской карты
- При недостатке средств на кошельке — списание с привязанной карты

### Кошелек
- Пополнение кошелька через кнопку "Пополнить"
- Указание суммы пополнения
- Списание с карты и зачисление на кошелек

### Push-уведомления
- Отдельный микросервис push-уведомлений (не через Google FCM)
- Уведомления отправляются конкретному пользователю системой сервиса
- Работают независимо от других сервисов

## Архитектура

### Микросервисы

| Сервис | Порт | Описание |
|--------|------|----------|
| `auth` | 3001 | Авторизация и управление пользователями |
| `api` | 3002 | Основной API-шлюз, проксирование запросов |
| `push` | 3003 | Push-уведомления (Web Push API) |
| `app` | 3004 | Управление версиями и скачиванием APK |

### Общая база данных
Все микросервисы используют общую JSON-базу в директории `data-db/`:
- `users.json` — пользователи
- `sessions.json` — сессии авторизации
- `push-subscriptions.json` — подписки на push-уведомления
- `app-versions.json` — версии приложения и настройки обслуживания
- `metrics.json` — метрики состояния сервисов

### Отказоустойчивость
- Каждый микросервис независим — сбой одного не ломает остальные
- PM2 с автоперезапуском (1 попытка) при сбое
- При повторном сбое сервис отключается временно
- Фронтенд скрывает элементы отключённого сервиса

## Окружения

| Ветка | Окружение | Назначение |
|-------|-----------|------------|
| `main` | Stable | Релизная версия для всех пользователей |
| `dev` | Test | Разработка и тестирование новых версий |

## Android приложение

- **minSdkVersion**: 29+
- **Архитектура**: Universal (armeabi-v7a, arm64-v8a, x86, x86_64)
- **Тип**: WebView приложение, загружает сайт онлайн
- **Хранение**: Cookie и идентификаторы сохраняются локально

## Установка и запуск

### Локальный запуск сервисов

```bash
# Установка зависимостей для всех сервисов
cd microservices/auth && npm install
cd ../api && npm install
cd ../push && npm install
cd ../app && npm install

# Запуск всех сервисов (из корня проекта)
npm install -g pm2
pm2 start ecosystem.config.cjs
```

### Структура проекта

```
VeloPro1/
├── microservices/
│   ├── auth/        # Сервис авторизации
│   ├── api/         # API-шлюз
│   ├── push/        # Push-уведомления
│   └── app/         # Управление версиями
├── data-db/         # Общая JSON-база
├── site/            # WebView сайт (фронтенд)
├── android-app/     # Android WebView приложение
├── ecosystem.config.cjs  # PM2 конфигурация
└── README.md
```

## API

Все микросервисы возвращают ответ в едином формате:

```json
{
  "success": true,
  "data": { ... },
  "error": null
}
```

При ошибке:

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "ERROR_CODE",
    "message": "Описание ошибки"
  }
}
```
